===============================================================================
                    HOW TO INSTALL THE ML BOT IN MT5
===============================================================================

STEP 1: Open MT5 and find your data folder
-------------------------------------------
1. Open MetaTrader 5
2. Click: File → Open Data Folder
3. A folder will open (something like C:\Users\...\MetaQuotes\Terminal\...)
4. Keep this window open


STEP 2: Copy these 3 files
-------------------------------------------

FILE 1: The Bot
---------------
From your git repo:
  my-trading-work\Adaptive_Bitcoin_ML_Enhanced.mq5

To MT5:
  [YourMT5Folder]\MQL5\Experts\Adaptive_Bitcoin_ML_Enhanced.mq5

Just drag and drop into the Experts folder!


FILE 2: The Include File
------------------------
From your git repo:
  my-trading-work\Include\Random Forest.mqh

To MT5:
  [YourMT5Folder]\MQL5\Include\Random Forest.mqh

Drag into the Include folder!


FILE 3: The AI Model
--------------------
From your git repo:
  my-trading-work\Common\Files\BTCUSD.PERIOD_D1.cluster-centroids.onnx

To MT5:
  Go UP one folder (back to Terminal folder)
  Then into: Common\Files\BTCUSD.PERIOD_D1.cluster-centroids.onnx

Drag into Common\Files\


STEP 3: Compile in MT5
-------------------------------------------
1. In MT5, press F4 (opens MetaEditor)
2. On the left side, expand "Experts"
3. Double-click "Adaptive_Bitcoin_ML_Enhanced"
4. Click the Compile button (or press F7)
5. Should say "0 errors"


STEP 4: Find it in Strategy Tester
-------------------------------------------
1. In MT5, press Ctrl+R (opens Strategy Tester)
2. In "Expert Advisor" dropdown, look for: Adaptive_Bitcoin_ML_Enhanced
3. If you see it = SUCCESS! Ready to test!
